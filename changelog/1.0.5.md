Lyrics from Spotify and Spicy Lyrics through a Spicetify extension. Not yet played through by the author, report anything that looks wrong.

- New optional Spicetify extension `glass-lyrics-bridge.js` (in the release files and in the `spicetify` folder of the repository). In the Spotify desktop app it sends the island the line-synced lyrics Spotify shows, then the word-timed lyrics of Spicy Lyrics if that extension is installed. It reads the cache Spicy Lyrics fills on its own and sends no requests to the Spicy Lyrics server
- The game listens on `127.0.0.1:47823` only and accepts lyrics only from the Spotify app. No token or cookie reaches the mod
- Source order: word-timed lyrics from the bridge, word-timed LRCLIB, NetEase yrc, line-synced lyrics from the bridge, then line-synced LRCLIB and NetEase. Word-timed lyrics that arrive after line-synced ones replace them on the fly
- New setting **Spotify bridge**, on by default
