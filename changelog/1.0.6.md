Fixes for the Spotify bridge. Not yet played through by the author, report anything that looks wrong.

- The game now listens on the IPv4 address `127.0.0.1:47823` explicitly. Under Forge the Java loopback address resolves to IPv6 `::1`, the extension knocks on `127.0.0.1`, and no parcel ever arrived; the shared lyrics core with BattleCraft is fixed here
- `glass-lyrics-bridge.js`: songs Spotify marks up by syllables (`SYLLABLE_SYNCED`) were dropped entirely; their line timings are now sent as line-synced lyrics. Syllable-timed lyrics still come from Spicy Lyrics, each syllable with its own time window and the letters inside it lighting one by one. Replace the file in `%APPDATA%\spicetify\Extensions` and run `spicetify apply`
